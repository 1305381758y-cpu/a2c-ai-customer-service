# A2C 智能客服后台前端重设计 PRD

版本：V2.0
日期：2026-07-12
范围：商户端、平台管理端共用后台前端

## 1. 产品目标

将现有功能型后台升级为可长期运营的 SaaS 工作台：商户能快速找到入口、理解客户当前阶段、完成配置和人工接管；平台管理员能跨商户查看异常、数据和模型调用。重设计不改变现有业务接口和自动客服规则，重点改善信息架构、信息密度、状态反馈、滚动和响应式表现。

## 2. 用户与核心任务

### 商户管理员

- 查看今日客户、会话、回复和接管数据。
- 在训练中心上传话本、聊天记录和图片素材。
- 配置国家、A2C、AI、邀请码和导师 Telegram 链接。
- 查看客户完整对话并进行人工接管。
- 编辑话本节点并确认启用版本。

### 商户运营

- 快速处理未读会话和待接管客户。
- 查看客户资料、当前流程节点和历史消息。
- 发送人工消息、标记状态、查看复盘。
- 只能查看只读配置，不能修改核心规则。

### 平台管理员

- 管理商户、后台账号和全局配置。
- 查看跨商户统计、模型调用、操作日志和异常。
- 进入指定商户上下文后再修改商户数据，避免误操作。

## 3. 信息架构

商户端导航收敛为：

1. 总览
2. 会话
3. 客户
4. 接管
5. 训练中心
6. 模拟训练
7. 话本流程
8. 智能体配置
9. 设置

平台管理端保留：总览、模型调用、操作日志、商户、后台账号，以及进入商户上下文后的同一套运营页面。

训练中心作为商户的统一喂数入口，样本、素材、知识库保留为内部数据类型，不作为首要导航入口。

## 4. 页面模板

### 数据列表页

适用：客户、接管、模型调用、操作日志、商户管理、意图学习。

固定结构：页面标题与说明 → 核心统计 → 筛选工具栏 → 表格/列表 → 详情抽屉。

要求：服务端分页、真实总数、时间精确到秒、搜索防抖、筛选无结果状态、加载失败重试、行点击详情、导出入口。

### 配置中心页

适用：设置、智能体配置、话本流程。

固定结构：当前状态摘要 → 左侧分组 → 右侧编辑区 → 保存/检测反馈 → 修改记录。

要求：分组独立保存、敏感字段脱敏、保存前显示影响范围、高风险操作二次确认、成功后局部刷新并保留滚动位置。

### 会话工作台

固定结构：客服账号栏 → 客户栏 → 对话主区 → 可收起辅助抽屉。

要求：四个区域独立滚动；右侧辅助区默认收起或窄化；聊天输入框固定底部；未读数明确；当前商户、国家、语言、流程节点始终可见；详情信息进入抽屉或折叠面板。

## 5. 关键交互

- 所有按钮必须有加载中、成功或失败反馈。
- 删除、停用、清空、恢复默认、启用话本必须二次确认，并说明影响范围。
- 列表行点击打开详情，不使用隐蔽的小图标作为唯一入口。
- 客户和会话默认按当日显示，可切换北京时间/国家时间，筛选包含时分秒。
- 空数据必须给出原因和下一步按钮；接口失败必须提供重试。
- 话本启用前显示校验结果，缺少注册链接、邀请码或导师链接时阻止启用。
- 会话状态变更后立即刷新当前行、统计和未读数，不能只显示 Toast。

## 6. 验收指标

- 1366×768、1440×900、1920×1080 下主页面无遮挡、无横向溢出。
- 1024 宽度下会话工作台切换为可收起区域，不出现内容被截断。
- 所有数据页具备加载、空数据、失败、无权限、无搜索结果五种状态。
- 所有时间筛选可到秒，页面显示遵循当前时间模式。
- 会话、客户、设置、话本流程的关键按钮均有可验证的状态变化。
- 前端不出现未翻译的操作英文；品牌名和文件格式白名单除外。

## 7. 非目标

- 本次不改变 A2C Webhook、AI 回复、话本状态机、邀请码分配和 Telegram 接管业务规则。
- 本次不新增模型供应商和数据表。
- 本次不把所有页面改成营销风格，后台优先保证扫描效率和操作稳定性。
