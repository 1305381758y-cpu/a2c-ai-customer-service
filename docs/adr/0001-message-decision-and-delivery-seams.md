# ADR-0001：客户消息决策与发送适配的统一接缝

## 状态

已接受

## 背景

客户消息会经过基础分析、上下文意图、严格流程、自定义话本、自然化和普通回复。过去多个调用方都可以决定下一步，导致启用自定义话本后仍出现系统文案、节点内问题跳步和普通 AI 串入。真实 A2C、模拟训练、跟进、教程图片和接管通知也曾分别判断发送模式。

## 决策

1. 严格流程启用后，客户可见的业务下一步只能由统一的回复计划决定；普通 AI 不能作为严格流程的后备决策者。
2. 自定义话本的节点文案优先于系统内置业务文案；系统内置文案只提供可复制模板和通用安全问答。
3. 大模型输出只能作为回复计划的理解/表达输入，不能直接改变流程状态、发链接、分配邀请码或触发接管。
4. 所有外发行为通过发送适配器，适配器负责模拟隔离、A2C Token 缓存、重试、限流、幂等和审计记录。
5. 邀请码和导师 Telegram 链接的分配范围固定为商户 + 国家/市场 + A2C 客服账号 + 会话。

## 后果

回复决策接口会变得更重要，但测试可以集中在一个接缝；一次修复能覆盖所有入口，维护 locality 和复用 leverage。节点内问答与节点推进需要分开验证，模型供应商可以替换而不改变业务流程。

## 验收标准

- 启用自定义话本时不会进入普通 AI 业务兜底。
- 客户在当前节点提问时，未满足完成条件前保持当前节点。
- 模拟训练不会调用 A2C 或 Telegram 发送。
- 不同客服账号、国家的资源不会互相分配。
