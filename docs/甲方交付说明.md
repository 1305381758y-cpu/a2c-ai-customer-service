# A2C AI 自动客服首版交付说明

## 交付内容

本版本是“样本驱动的 AI 话术/知识库训练 + 客户意图分析”后端服务，支持：

- 接收 A2C 客户消息 Webhook。
- 上传 Excel/CSV 优秀回复样本，上传后立即生效。
- 自动识别客户语言，并用客户一致的语言回复。
- 自动分析客户意图，使用固定意图标签保存。
- 从样本库检索相似样本，供 AI 生成回复。
- 自动抽取手机号和 Telegram 账号。
- 手机号 + TG账号齐全后，通过 Telegram 机器人通知人工接管。
- 接管后停止 AI 自动回复。

## 环境配置

复制 `.env.example` 为 `.env`，填写：

```bash
PORT=3000
DATABASE_URL=./data/app.db
INTERNAL_API_KEY=请改成强密码

A2C_BASE_URL=https://openapi.a2c.chat/api/openapi
A2C_APP_ID=甲方A2C_APP_ID
A2C_APP_SECRET=甲方A2C_APP_SECRET

OPENAI_API_KEY=OpenAI密钥
OPENAI_MODEL=gpt-5-mini

TELEGRAM_BOT_TOKEN=Telegram机器人Token
TELEGRAM_HANDOFF_CHAT_ID=人工接管群chat_id

PLATFORM_REGISTER_URL=平台开户链接
TG_REGISTER_GUIDE_URL=Telegram注册说明链接
```

如 OpenAI 账号未开通默认模型，可把 `OPENAI_MODEL` 改成该账号可用的 Responses API 文本模型。

## 上传训练样本

模板文件：`samples/training-samples-template.csv`

支持字段：

```csv
客户消息,标准回复,适用阶段,客户意图,语言,关键词,优先级,是否启用
```

导入命令：

```bash
curl -X POST http://127.0.0.1:3000/internal/training-samples/import \
  -H "X-API-Key: 请替换为INTERNAL_API_KEY" \
  -F "file=@samples/training-samples-template.csv"
```

查询样本：

```bash
curl "http://127.0.0.1:3000/internal/training-samples?enabled=true" \
  -H "X-API-Key: 请替换为INTERNAL_API_KEY"
```

## A2C Webhook 配置

把 A2C 后台 Webhook 地址配置为：

```text
https://你的域名/webhooks/a2c
```

系统收到 `CUSTOMER_MESSAGE` 后会：

1. 保存客户消息。
2. 分析语言和意图。
3. 抽取手机号和 TG 账号。
4. 检索训练样本。
5. 调用 OpenAI 生成回复。
6. 使用 A2C 当前接收账号发送回复。
7. 资料齐全后通知 TG 群人工接管。

## 查看客户会话

```bash
curl "http://127.0.0.1:3000/internal/conversations?limit=50" \
  -H "X-API-Key: 请替换为INTERNAL_API_KEY"
```

查看某个会话消息：

```bash
curl "http://127.0.0.1:3000/internal/conversations/会话ID/messages" \
  -H "X-API-Key: 请替换为INTERNAL_API_KEY"
```

## 固定意图标签

- `greeting`：打招呼、初次咨询。
- `ask_platform_register`：询问如何注册平台。
- `platform_register_done`：表示已完成平台注册。
- `ask_tg_register`：询问如何注册或提供 Telegram。
- `provide_phone`：提供手机号。
- `provide_telegram`：提供 TG 账号。
- `provide_phone_and_telegram`：同时提供手机号和 TG 账号。
- `ask_link`：索要注册链接或入口。
- `ask_promotion`：询问活动、优惠、奖励。
- `trust_concern`：质疑真实性、安全性、是否可靠。
- `need_help`：表示不会操作、需要协助。
- `human_request`：要求人工客服。
- `irrelevant_or_spam`：无关内容或垃圾消息。
- `unknown`：无法判断。

- `npm test` 通过。
- `npm run build` 通过。

- A2C Webhook 收到客户消息后能保存会话。
- 客户提供手机号 + TG账号后，Telegram 群收到人工接管通知。
