# 智能客服平台商户端与管理端生产级 PRD

## 1. 文档信息

| 项目 | 内容 |
|---|---|
| 产品名称 | 智能客服 |
| 文档类型 | 生产级产品需求文档 |
| 文档版本 | V1.0 |
| 适用范围 | 平台管理端、商户端、商户运营端 |
| 当前状态 | 规划与实施拆分 |

## 2. 产品目标

### 2.1 总体目标

将现有智能客服工作台重构为两个职责清晰的产品入口：

1. 管理端：管理商户、权限、费用、模型供应商、全局数据和系统运行状态。
2. 商户端：配置自己的接入渠道、国家、话本、Agent，并处理真实客户会话。

### 2.2 业务目标

- 商户可以独立完成接入、配置、训练、测试和上线。
- 管理员可以独立配置每个商户的单次会话金额和余额。
- 管理员可以为单个客户充值、调整余额和配置专属模型。
- 商户看不到平台级模型 Key、模型供应商和其他商户数据。
- 所有客户消息、会话、接管和模型调用可追溯。
- 高风险配置和删除操作有确认、日志和恢复能力。

### 2.3 非目标

- 本阶段不为每个客户部署独立模型进程。
- 本阶段不开放客户自由修改平台级计费规则。
- 本阶段不允许商户访问其他商户的数据。
- 本阶段不把训练素材自动直接发布为生产话术，必须经过审核或流程启用。

## 3. 用户角色与权限

### 3.1 平台管理员

可访问 `/admin`。

可执行：

- 创建、编辑、停用和删除商户。
- 创建和管理平台管理员、商户管理员、商户运营账号。
- 为商户设置单次会话金额、默认结算币种和商户余额。
- 为单个客户充值、扣减、编辑和删除余额流水。
- 为单个客户配置 AI 供应商和模型。
- 查看全平台总览、模型调用、日志、客户、会话和接管数据。
- 进入指定商户的管理详情。

不可执行：

- 不通过商户端配置 A2C 接入流程。
- 不直接替代商户进行日常客户回复。

### 3.2 商户管理员

可访问 `/merchant`。

可执行：

- 配置本商户 A2C 接入和客服账号。
- 配置国家、默认语言、注册链接、邀请码和 Telegram 导师链接。
- 上传训练资料、编辑话本、配置 Agent。
- 开启或关闭智能回复、模拟训练和主动跟进。
- 查看、回复、删除本商户客户和会话。
- 处理人工接管。

不可执行：

- 不修改模型供应商和平台模型 Key。
- 不修改单次会话金额和平台余额。
- 不查看其他商户数据。

### 3.3 商户运营

可执行：

- 查看总览、客户、会话和接管。
- 回复客户和处理人工跟进。
- 查看话本和 Agent 配置。
- 使用模拟训练。

只读或禁止：

- 不能修改核心配置。
- 不能删除客户和会话。
- 不能管理 A2C、邀请码、TG 导师链接。
- 不能启用或停用生产话本。


### 4.2 商户端导航

```text

接管
训练中心
模拟训练
话本流程
对话优化
接待角色

```

### 4.3 页面通用规范

- 每个页面必须有标题、说明、当前商户和主要操作。
- 所有时间使用北京时间或当前商户国家时间，筛选精确到秒。
- 所有列表采用服务端分页，统计数字使用 `COUNT(*)` 逻辑，不受当前列表页条数影响。
- 所有列表必须具备加载中、空数据、失败、无权限、无搜索结果和局部刷新状态。
- 删除、停用、清空、恢复、批量导入必须二次确认。
- 复杂信息使用详情抽屉或折叠面板，不在主列表全部展开。
- 后台页面不显示未翻译的英文按钮、状态和错误信息。

## 5. 管理端页面需求

### 5.1 管理端总览

#### 核心指标

- 商户总数。
- 客户总数。
- 会话总数。
- 今日新增客户数。
- 今日新增会话数。
- 今日重复会话数。
- 客户消息总数及筛选时间内消息数。
- 客服回复总数及筛选时间内回复数。
- 平均每个会话消息数。
- 待人工接管数。
- 注册完成数。
- TG 接管数。
- 商户余额总额。
- 模型调用成功率和失败率。

#### 筛选

- 时间范围：开始日期时间、结束日期时间。
- 时间基准：北京时间、商户国家时间。
- 商户：下拉选择，不允许手写商户 ID。
- 国家、状态和接管状态。

#### 验收标准

- 切换商户或时间后所有指标同时刷新。
- 指标不受列表分页影响。
- 昨日、今日和自定义区间边界按所选时区计算。

### 5.2 商户管理

#### 功能

- 商户增删改查。
- 商户管理员账号初始化。
- 商户状态启用、停用。
- 国家和默认语言配置。
- 单次会话金额设置。
- 商户余额调整。
- 默认结算币种显示为“默认币种”。
- 商户详情页查看客户、会话、模型和日志。

#### 高风险规则

- 删除商户前展示影响范围：客户、会话、训练内容、配置、余额流水。
- 停用商户后停止自动回复、A2C 接入和接管通知。
- 每次变更写入操作日志。

### 5.3 后台账号

#### 功能

- 账号增删改查。
- 角色分配。
- 商户绑定。
- 启用、停用和重置密码。
- 最后登录时间和登录失败记录。

#### 验收标准

- 商户管理员只能看到自己的商户。
- 商户运营无法访问核心配置操作。
- 管理端和商户端入口权限互斥，入口不匹配时显示明确提示。

### 5.4 管理端客户

#### 功能

- 按商户下拉筛选客户。
- 搜索客户账号、号码、昵称。
- 查看客户全部历史会话。
- 查看客户资料、流程、接管状态和余额。
- 客户余额充值、扣减、流水增删改查。
- 单客户 AI 供应商和模型配置。
- 删除客户及其全部会话、消息、记忆和流水。

#### 余额规则

- 余额以流水合计为准。
- 充值、扣减和流水修改必须记录操作人。
- 余额不足时，按平台设定规则标记会话费用状态。

### 5.5 管理端会话与接管

#### 功能

- 全平台会话检索。
- 按商户、客服账号、国家、流程节点、接管状态、异常状态筛选。
- 查看完整消息时间线和诊断信息。
- 查看会话费用、消息数量、回复模式、模型调用失败。
- 查看接管原因、联系方式和人工处理状态。

#### 管理边界

- 管理端默认以监管和排障为主。
- 需要回复客户时必须明确记录为平台人工操作。

### 5.6 模型调用

#### 功能

- 按商户下拉筛选。
- 供应商筛选。
- 模型筛选。
- 调用类型筛选：翻译、语言识别、意图识别、上下文理解、口语化改写、图片分析、复盘、普通回复、配置检测。
- 时间精确到秒。
- 总调用、成功、失败、成功率、平均耗时。
- 输入输出 Token、空响应、超时、错误原因。
- 查看请求摘要和响应摘要。

#### 验收标准

- 不把“翻译”作为唯一类型展示。
- 调用统计按供应商、商户、任务类型分别聚合。
- 失败调用可以定位到真实请求和响应摘要。

### 5.7 操作日志

- 操作人。
- 商户。
- 操作类型。
- 操作对象。
- 修改前后内容。
- 时间、结果和错误原因。
- 支持按商户下拉、操作类型和时间筛选。

## 6. 商户端页面需求

### 6.1 商户总览

#### 核心指标

- 客户总数。
- 今日新增客户数。
- 会话总数。
- 今日新增会话数。
- 今日重复会话数。
- 客户消息总数。
- 今日客户消息数。
- 已回复消息总数。
- 今日已回复消息数。
- 平均每个会话消息数。
- 待处理接管数。
- 链接打不开异常数。
- 模型调用异常数。

### 6.2 会话工作台

#### 页面结构

1. 客户列表区：账号、昵称、未读数、当前节点、最后消息时间。
2. 对话区：消息、原文、译文、媒体、输入框、快捷回复。
3. 客户详情区：资料、流程、接管、复盘、历史记录。

#### 交互要求

- 客户列表、聊天记录、右侧详情分别独立滚动。
- 客户详情默认收起，聊天区优先保证可用高度。
- 话本流程默认显示为紧凑进度条，点击后展开节点详情。
- 输入框固定在对话区底部，不被右侧面板遮挡。
- AI 建议回复必须支持编辑后发送。
- 手动发送必须明确显示发送中、成功和失败。
- 删除会话必须二次确认并彻底删除。

### 6.3 客户

- 客户列表服务端分页。
- 支持账号、号码、昵称、状态、国家、流程节点、时间筛选。
- 点击客户打开详情抽屉。
- 查看客户全部会话。
- 一键进入最近会话。
- 查看资料完整度、注册状态、TG 状态、接管状态。
- 商户管理员可删除客户，运营只读。

### 6.4 接管

- 待接管、处理中、已完成三个状态。
- 接管原因必须结构化展示。
- 支持人工备注、负责人、处理时间。
- 支持从接管记录直接打开完整会话。
- TG 导师链接分配记录可追溯。

### 6.5 训练中心

#### 输入

- Word。
- TXT。
- Excel。
- CSV。
- Markdown。
- 图片和截图。

#### 处理流程

```text
上传资料
  -> 自动解析
  -> 生成话本草稿、知识草稿和样本草稿
  -> 商户审核修改
  -> 预览模拟
  -> 手动启用
  -> 应用于新会话
```

#### 原则

- 导入默认是草稿。
- 解析失败不能丢失原文件。
- 未审核内容不得直接影响真实客户。
- 商户端不要求用户理解“素材、知识库、样本”的技术区别。

### 6.6 模拟训练

- 输入模拟客户消息。
- 使用当前商户话本、Agent 和配置。
- 显示识别意图、当前流程、下一步动作和客户可见回复。
- 不调用真实 A2C 发送接口。
- 不发送 TG 通知。
- 不扣除真实会话费用。
- 支持重置和导出模拟记录。

### 6.7 话本流程

#### 功能

- 上传话本自动生成节点。
- 创建、复制、编辑、删除流程。
- 节点增删改查。
- 节点顺序调整。
- 设置触发条件和下一步条件。
- 设置是否发送注册链接、邀请码和注册教程图片。
- 设置 Telegram 下载、导师链接和人工接管节点。
- 草稿、启用、停用和历史版本恢复。

#### 生产规则

- 启用自定义话本后，系统内置话本不得抢答。
- 节点内客户问答不限次数。
- 客户问题优先回答，再判断是否满足下一节点条件。
- 只有明确满足条件才推进节点。
- 重复无法打开注册链接达到阈值时，自动转人工并记录原因。

### 6.8 对话优化

- 查看错误意图识别。
- 修改正确意图。
- 查看答非所问回复。
- 查看重复话术。
- 查看客户常见疑问。
- 生成候选优秀样本。
- 商户确认后加入训练中心。

### 6.9 接待角色

- Agent 名称。
- 角色定义。
- 语气和表达风格。
- 核心目标。
- 必须遵守。
- 禁止事项。
- 不确定问题口径。
- 转人工条件。
- 主动跟进时间。
- 单次回复长度。
- 版本记录和恢复。

### 6.10 商户设置

#### 运行模式

- 智能回复开关。
- 模拟训练开关。
- 话本流程开关。
- 2 分钟主动跟进开关。

#### A2C 接入

- A2C 密钥和应用密钥。
- 客服账号同步。
- Token 缓存状态和有效期。
- Webhook 地址。
- 发送失败重试和限频状态。

#### 国家与引导

- 国家名称。
- 自动带入国家代码。
- 自动带入默认语言。
- 注册链接。
- 注册说明。
- 注册教程图片。

#### 客服账号与邀请码

- 客服账号绑定国家。
- 邀请码池增删改查。
- 客服账号绑定邀请码池。
- 邀请码状态和使用记录。

#### TG 接管

- 导师 TG 链接增删改查。
- 优先级。
- 轮询次数。
- 轮询分配。
- 接管通知模板。
- 接管触发条件。

商户端禁止出现：

- 智能供应商配置。
- 模型 Key。
- 模型名称。
- 平台级单次会话金额。
- 其他商户数据。

## 7. 核心业务流程

### 7.1 商户开通流程

```text
管理员创建商户
  -> 创建商户管理员
  -> 设置单次会话金额和余额
  -> 商户登录
  -> 配置国家和语言
  -> 配置 A2C
  -> 同步客服账号
  -> 配置邀请码和注册链接
  -> 配置 TG 导师链接
  -> 上传话本和训练资料
  -> 模拟训练
  -> 启用话本和智能回复
  -> 开始接收真实客户
```

### 7.2 客户会话流程

```text
接收消息
  -> 创建或恢复客户
  -> 识别客户语言和意图
  -> 读取当前话本节点
  -> 先回答客户问题
  -> 判断是否满足下一节点条件
  -> 生成自然回复
  -> 发送消息
  -> 保存消息、调用、流程和费用记录
  -> 达到接管条件后通知人工
```

### 7.3 模拟训练流程

```text
模拟客户输入
  -> 读取商户配置
  -> 执行同一套流程和意图理解
  -> 生成模拟回复
  -> 记录诊断信息
  -> 禁止真实通道发送
```

## 8. 数据与接口要求

### 8.1 数据隔离

- 所有商户数据必须带 `merchantId`。
- 商户端接口必须从登录态获取商户 ID，禁止信任前端传入的商户 ID。
- 管理端切换商户必须使用下拉选择，并在页面显示当前商户。
- 客户记忆、会话、训练内容、邀请码和导师链接不得跨商户命中。

### 8.2 统计要求

- 总览统计使用数据库聚合查询。
- 列表分页不能影响总数。
- 时间区间先按选定时区转换为 UTC，再执行查询。
- 统计接口返回统计口径和时间区间，方便排查。

### 8.3 配置版本

以下配置必须有版本记录：

- 商户配置。
- Agent 配置。
- 话本流程。
- TG 导师链接。
- 邀请码池。
- 结算设置。

## 9. 非功能要求

### 性能

- 首屏核心数据目标小于 2 秒。
- 列表必须服务端分页。
- 搜索输入防抖 300 毫秒。
- 长对话按消息分页或分段加载。
- 大文件解析使用异步任务。

### 稳定性

- A2C Token 必须缓存，不得每次请求重新生成。
- A2C 认证失败时只重新认证并重试一次。
- 模型失败不得阻断客户消息入库。
- 模拟训练绝不调用真实 A2C 发送。
- 配置保存失败不得清空当前页面数据。

### 安全

- 密钥只显示脱敏内容。
- 密码只允许重置，不回显原密码。
- 管理端和商户端权限后端强制校验。
- 删除和停用操作二次确认。
- 所有敏感操作写入日志。

## 10. 分阶段实施计划

### 第 1 阶段：入口和权限边界

目标：确保管理端和商户端职责真正分离。

任务：

- 固化 `/admin` 和 `/merchant` 两个入口。
- 完善角色权限矩阵。
- 管理端隐藏 A2C 配置入口。
- 商户端隐藏模型供应商和模型 Key。
- 所有管理端商户筛选改为下拉选择。
- 补齐越权、入口不匹配和无权限状态。

验收：三种角色分别登录，页面和操作权限符合本 PRD。

### 第 2 阶段：管理端商户与结算中心

任务：

- 商户增删改查。
- 商户管理员账号管理。
- 单次会话金额。
- 商户余额。
- 默认币种展示。
- 客户余额流水增删改查。
- 客户单独模型配置。

验收：修改结算配置后刷新不丢登录态，余额和流水统计一致。

### 第 3 阶段：商户会话工作台

任务：
