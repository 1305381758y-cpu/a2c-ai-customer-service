# UI 工程化改造验收清单

更新时间：2026-07-09

## 本轮已落地内容

- 新增统一页面状态组件：加载中、空数据、加载失败、无权限/无结果可复用。
- 表格组件支持统一加载、错误、空状态和重试入口。
- 删除类操作改为统一二次确认弹窗，不再直接使用浏览器默认确认框。
- 多个页面补齐请求失败提示，避免接口失败时被误认为“暂无数据”。
- 会话详情、客户记忆、对话复盘、模拟训练、设置、客户、知识库、总览等页面补齐局部错误状态。
- 新增浏览器级滚动冒烟测试，覆盖平台管理员和商户管理员的主要页面。
- 滚动冒烟测试已扩展为交互冒烟测试：验证总览、模型调用、客户、会话的时间筛选请求确实携带 `startAt`、`endAt` 和 `timeZone`。
- 模型调用页已增加请求级验证：供应商和调用类型筛选会真实传到统计接口，并联动顶部统计、成功率和明细表。
- 验证客户页“当前筛选导出”和会话页“导出全部 / 导出当前账号”会发起正确导出请求。
- 修复会话页在北京时间模式下未显式传递 `Asia/Shanghai` 的问题，便于统计筛选和问题排查保持一致。
- 新增后台文案冒烟检查，拦截常见英文按钮词和高频英文夹中文功能名，包括 `AI供应商`、`AI建议`、`A2C AI` 等可见残留。
- 修复客户索引重建时可能取到旧会话资料的问题。

## 新增验证命令

```bash
npm run ui:scroll-smoke
```

该命令会：

1. 先执行生产构建。
2. 使用临时 SQLite 数据库启动本地服务。
3. 自动登录平台管理员。
4. 创建一个临时商户管理员。
5. 分别用平台管理员和商户管理员访问主要后台页面。
6. 对页面内可滚动区域执行滚动到底部检查。
7. 验证关键时间筛选、模型调用供应商和调用类型筛选、客户/会话导出、智能体配置保存、话本流程创建编辑删除、设置页高风险开关点击反馈。
8. 输出截图到 `output/playwright/scroll-smoke/`。

该命令不会连接线上数据库，也不会修改真实客户数据。

## 本轮还未完全解决的结构问题

这些问题已经在 `docs/ui-optimization-master-analysis.md` 中列为后续工程化方向，本轮只做了基础设施和高风险状态补齐：

- `frontend/src/main.tsx` 仍然过大，后续应拆成页面目录。
- `frontend/src/styles.css` 仍然是单文件累积，后续应拆成 token、layout、components、pages。
- 表格组件仍偏基础，后续应升级为带服务端分页、列配置、详情抽屉的数据表格。
- 设置页、会话页、话本流程页仍需要按工作台/配置中心/流程编辑器模板继续重构。
- 权限状态、版本记录、配置影响范围提示还需要继续统一到所有高风险配置页。

## 后续改造优先级

1. 会话页：稳定三栏布局、收起右侧辅助区、统一消息原文/译文密度。
2. 设置页：按配置类型分组，独立保存、独立检测、独立反馈。
3. 话本流程页：节点时间线 + 右侧编辑抽屉，启用前做流程完整性校验。
4. 客户页：服务端分页、时间筛选、详情抽屉、导出入口统一。
5. 模型调用页：供应商/类型筛选、失败原因排行、调用明细抽屉。
